# CSC 106 Academic Portfolio & Planner

A responsive, multi-page student website built with semantic HTML5, modern CSS3, and vanilla JavaScript (no frameworks).

## Pages

- `index.html` — home, biography, and HTML5 video player
- `about.html` — education table, skills, career goals, hobbies
- `projects.html` — three-project grid
- `planner.html` — task manager with `localStorage`
- `contact.html` — validated contact form

## How to view

Open `index.html` in a browser.

## Replacing placeholder images and added audio

SVG fallbacks live in `images/`:

| File | Used on |
| --- | --- |
| `images/profile.jpg` | Home hero photo |
| `images/intro.mp4` | Home video (optional) |
| `images/project1.png` | Projects card 1 |
| `images/project2.png` | Projects card 2 |
| `images/project3.png` | Projects card 3 |

`cd audio`
